# Architecture Decision Records (ADRs)

This folder contains **Architecture Decision Records (ADRs)** for the project. An ADR is a lightweight document that records a significant technical or design decision, along with its context, trade-offs, and consequences.

## Purpose

Instead of asking *"Why did we choose this technology?"* or *"Why is this configured this way?"*, you can look in this folder to understand the context and reasoning behind key architectural choices.

ADRs help us:
- Maintain context as team members change or time passes.
- Document trade-offs and alternatives that were evaluated.
- Prevent re-hashing past decisions without new context or requirements.
